# AKAN NAME GENERATOR

## DESCRIPTION

A web application that calculates the day of the week a user was born 
and assigns them an Akan name based on their gender. Akan names come from Ghanaian culture, where children are named based on the day they were born.

The application provides a visually appealing and user-friendly experience by validating user inputs, displaying the generated Akan name, maintaining a history of previously generated names, and automatically cearing the form after each succesful submission.

## FEATURES

- Generate an Akan name based on the user's date and date of birth and gender.
- Validate user input to ensure correct day, month, and year values.
- Display alert messages for invalid or incomplete submissions
- Automatically display the generated Akan name and the corresponding day of the week.
- Smooth the scrolling navigation between sections of the website.
- Maintain a history of generated Akan names.
- Automatically clear the form after every successful submission.
-Responsive and vissually polished user interface.

## How to use

1. Open the application in your browser.
2. Navigate to the "Generate" section.
3. Enter your date, month, and year of bitrth.
4. Select your gender from the dropdown menu.
5. Click the "Generate Name" button.
6. View your Akan name and the day of the week you were born.
7. Check the "History" section to view previously generated names.
